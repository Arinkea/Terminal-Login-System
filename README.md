# 🔐 Terminal Login System

Мини-система входа в терминал, написанная на Python с использованием библиотеки Rich.

Проект создан в процессе изучения Python.

---

## 📌 Возможности

- Авторизация пользователей через словарь
- Красивый вывод информации в консоль (Rich)
- Простая структура базы пользователей
- Легко добавлять новых пользователей
- Учебный проект для начинающих

---

## 🧰 Используемые технологии

- Python 3
- Rich

---

## ▶️ Как запустить проект
скачайте Файел database.py
Откроете терминал и пропишите cd Место росположения фаела.
После чего пропишите pip install rich
и наконечто можно запускать python database.py
